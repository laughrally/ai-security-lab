生成AIと情報漏洩について、中小企業の現場で起きることを書いています
生成AIの「学習させない設定」で防げること、防げないこと
オプトアウトすれば安全、という理解は半分しか当たっていない。設定で消えるリスクと、設定では一切動かないリスクを分けて整理します。
2026-10-27　設定 / ChatGPT / 基礎
生成AIに社外秘を入れてしまった。最初の1時間にやること
やってしまった後にまずすべきなのは、履歴の削除ではありません。順番を間違えると、後から何も説明できなくなります。
2026-10-27　インシデント / 初動 / 実務
社内の生成AI利用ガイドライン、最低限これだけ書けばいい
立派な規程を作ろうとして止まるくらいなら、A4一枚で今週から回したほうがいい。そのまま使える文面を置いておきます。
2026-10-27　ガイドライン / ひな形 / 実務
シャドーAIの見つけ方。禁止しても使われている前提で探す
会社が許可していないAIを、社員が勝手に使っている状態。禁止令を出すと見えなくなるだけで、なくなりはしません。
2026-10-27　シャドーAI / 実態把握 / 実務
顧客情報を生成AIに入れると、個人情報保護法上どうなるか
入力した瞬間に即違法、という話ではありません。何が問題になるのか、どこで線が引かれるのかを条文に沿って整理します。
2026-10-27　法令 / 個人情報 / 実務
「うちみたいな小さい会社は狙われない」が通らなくなった理由
狙われるのは情報を持っているからではなく、取引先につながっているから。生成AIはその経路を一段増やしました。
2026-10-27　中小企業 / サプライチェーン / 背景
生成AIの情報漏洩、実際に報じられていること
サムスンの件が有名ですが、本当に見るべきは「やった本人に悪意がない」という共通点のほうです。
2026-10-27　事例 / 背景 / 基礎
議事録AI・文字起こしツールの落とし穴
入力している自覚がないまま、社内で一番濃い情報を外に出している。録音ボタンひとつで起きます。
2026-10-27　議事録AI / ツール / 実務
製造業で図面や仕様書を生成AIに入れる前に
手元にある図面の多くは預かりものです。自社の判断では出せません。ここが他の業種と違う。
2026-10-27　製造業 / 業種別 / 実務
士業が顧問先の情報を生成AIに入れるとき
顧問先は「先生に話した」つもりで、「先生とAI事業者に話した」とは思っていません。そのずれが問題になります。
2026-10-27　士業 / 業種別 / 守秘義務
Microsoft 365 Copilot を業務で使うときに確認すること
データは社外に出ません。代わりに、社内で見えてはいけないものが社内の人に見えるようになります。
2026-10-27　Copilot / ツール / 導入
「社員教育を実施した」と取引先に示すには何が要るか
対策していることと、していると示せることは別です。実際にやっているのに証明できない会社が多い。
